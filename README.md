# Flight Price Analysis – EDA and Feature Engineering

## Project Overview

This project focuses on analyzing flight ticket prices using Python. It involves understanding the dataset, performing Exploratory Data Analysis (EDA), cleaning data, and applying feature engineering techniques to prepare the data for further analysis.

The project helps identify patterns and relationships between flight details and ticket prices.

## Objectives

- Understand the flight price dataset.
- Perform data inspection and cleaning.
- Identify and handle missing values and duplicate records.
- Explore numerical and categorical features.
- Analyze relationships between flight details and ticket prices.
- Apply feature engineering techniques.
- Convert categorical columns into numerical format using One-Hot Encoding.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Dataset Information

The dataset contains flight-related information, including:

- Airline
- Source
- Destination
- Date of Journey
- Departure Time
- Arrival Time
- Duration
- Total Stops
- Route
- Additional Information
- Price

## Project Workflow

### 1. Data Loading
- Imported the required Python libraries.
- Loaded the flight price dataset.
- Displayed the first and last few records.

### 2. Data Understanding
- Checked dataset shape and columns.
- Examined data types and statistical information.
- Identified numerical and categorical columns.

### 3. Data Cleaning
- Checked for missing values.
- Identified and removed duplicate records.
- Handled missing values where required.

### 4. Exploratory Data Analysis (EDA)
- Performed univariate analysis.
- Performed bivariate analysis.
- Used histograms and box plots.
- Analyzed flight prices across airlines, sources, and destinations.
- Explored correlations between numerical features.

### 5. Feature Engineering
- Extracted day, month, and year from the journey date.
- Extracted hours and minutes from departure and arrival times.
- Converted flight duration into numerical features.
- Converted total stops into numerical values.
- Removed unnecessary columns where appropriate.

### 6. Categorical Encoding
- Applied One-Hot Encoding using Scikit-learn.
- Converted categorical features such as Airline, Source, and Destination into numerical columns.

### 7. Final Dataset
- Checked the final dataset.
- Saved the processed data as a CSV file.
